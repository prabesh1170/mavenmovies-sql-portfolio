

# MavenMovies SQL Analytics Portfolio

## Project Overview

This portfolio explores a movie-rental business database using SQL. It focuses on customer behaviour, rental activity, recorded payments, film performance, inventory availability, and business reporting.

The goal is to develop practical SQL skills while answering realistic business questions and documenting the reasoning behind each analysis.

## Objectives

- Analyse customer rental behaviour.
- Summarise recorded payments and trends.
- Identify popular films and categories.
- Explore inventory and rental availability.
- Validate data and investigate possible inconsistencies.
- Translate query results into evidence-based business recommendations.

## Tools and Technologies

- SQL — query writing and data analysis
- MySQL — intended database environment; confirm compatibility with your supplied database
- GitHub — version control and project documentation
- Optional future extension: a business intelligence dashboard

## Key Business Questions

1. Which customers rent films most frequently?
2. How do recorded payments vary over time?
3. Which films and categories have the highest rental counts?
4. How does rental activity differ across stores?
5. Which inventory copies are available for rental at a given point?
6. What data-quality issues could affect the analysis?

## Methodology

Each analysis documents the business question, relevant tables, SQL query, assumptions, validation steps, results, and recommendations.

All numerical findings and conclusions will be based on queries executed against the database. Recorded payment revenue will not be presented as profit without suitable cost data.

## Learning Goals

- Build confidence with SQL fundamentals and joins.
- Use aggregation, subqueries, CTEs, and window functions.
- Validate results and avoid double-counting.
- Write readable and maintainable SQL.
- Communicate technical results in business language.
